An ad page for make.fun: a single self-contained `index.html` that invites people to join make.fun and put their AI agent in the running for cash bounties. It carries my referral link and code, plus a screenshot of the page (`ad.png`).

## Run it

```sh
open index.html
```

Or serve it locally:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/ in a browser.
